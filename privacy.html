Privacy Policy

Effective date: 2 October 2026

This policy covers two private Google OAuth applications operated by the owner of Saturn Override: TAO Ops ChatGPT Bridge and Shadow Advisor Host. Neither application is offered to the public. Each is authorized only with the owner's own Google account and accesses only that account's data.

TAO Ops ChatGPT Bridge

  • Scope requested: https://www.googleapis.com/auth/drive.file only. The application refuses to run with a token that grants any broader or additional scope.
  • Data accessed: one Google Sheet that the application created itself. The ID of that sheet is fixed in the application's configuration, and any other sheet is refused. Under the drive.file scope, Google does not give the application access to the owner's other files.
  • What it does: it reads command rows from the sheet, checks them, and records accepted commands in the owner's private operations ledger. It then appends receipt and status rows to the same sheet. It does not edit or delete the command rows.

Shadow Advisor Host

  • Scope requested: https://www.googleapis.com/auth/drive. This scope is needed because the files it must read and update in that folder were created by other tools.
  • Data accessed: one Google Drive folder owned by the owner, used for daily research handoffs. During one-time setup, the application reads the signed-in account's email address to confirm it is the owner's account, and searches Drive by name to find that folder.
  • What it does: it uploads daily research files into the folder and reads them back to verify them. It updates a pointer file in the folder, reads files in the folder's return area into a local copy, and moves its own temporary folders to the Drive trash. It is designed to work only inside that folder.

Where data and credentials are kept

Both applications run only on a private server used for the owner's own automation. Data they read from Google is stored on that server. Bridge commands go into the operations ledger, and Shadow Advisor return files go into a local copy. The owner's own automated assistants on that server may process this data, solely to carry out the owner's tasks.

Each application's OAuth token is stored on that server in its own separate file, readable only by the server account that runs the applications. Tokens are not shared between the two applications and are not published or shared with anyone.

Sharing and use

Google user data obtained through these applications is not sold. It is not used for advertising, and it is not shared with or transferred to any third party for their own use.

Other tools the owner uses, such as ChatGPT's own Google connection, may also read or write the same sheet or folder under their own separate authorizations. This policy does not cover those tools.

Retention and revocation

The owner controls how long this data is kept and can delete it at any time. Access for either application can be revoked at any time at https://myaccount.google.com/permissions. After access is revoked, the application can no longer reach Google data.
