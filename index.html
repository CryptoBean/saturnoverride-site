Saturn Override

Saturn Override is a private, owner-operated tooling account. It is not a product or service and is not offered to the public. There are no sign-ups, accounts or customers.

Google OAuth applications

The owner uses two private Google OAuth applications, each authorized only with the owner's own Google account:

  • TAO Ops ChatGPT Bridge reads and writes one dedicated Google Sheet that the app itself created as a command inbox, using the drive.file scope. It relays the owner's commands from that sheet to a private operations ledger and writes processing receipts back to the sheet.
  • Shadow Advisor Host reads and writes files in one Google Drive folder owned by the owner, using the Drive scope. It publishes daily research handoff files to that folder and reads them back to verify them.

How these applications handle Google data is described in the privacy policy.
